# Contributing

Run `python -m unittest discover -s tests -v` and `python -m openwatch demo`.
Use Python 3.11 or newer. Runtime code should remain standard-library-only until a
dependency has a documented need. Include a small synthetic reproducer for bugs.
Adapter proposals should identify their public use case, completeness semantics,
timeouts and failure behavior. Never submit credentials, browser profiles, real
recipient IDs, databases, account data or copied private configurations.

Discuss contract changes in an issue before expanding the API. No performance,
delivery or availability claims without reproducible evidence.
